# Calculator

A simple web calculator built with **HTML**, **CSS**, and **JavaScript**.

## Objective
To create a functional, user-friendly calculator that performs basic arithmetic operations with a clean and responsive interface.

## Features
- Basic math operations (addition, subtraction, multiplication, division)
- Responsive design that works on desktop and mobile devices
- Keyboard support for enhanced usability
- Clear and delete functionality
- Error handling for invalid operations

##  Steps Performed

### 1. HTML Structure
- Created the calculator layout with display screen and button grid
- Organized buttons for digits (0-9), operators (+, -, ×, ÷), and functions (C, =)

### 2. CSS Styling
- Designed a modern, clean interface with proper spacing
- Implemented responsive design using CSS Grid and Flexbox
- Added hover and active states for better user interaction
- Ensured mobile-friendly layout with media queries

### 3. JavaScript Functionality
- Implemented calculation logic for basic arithmetic operations
- Added keyboard event listeners for keyboard support
- Created input validation and error handling
- Managed calculator state (current input, previous input, operator)

### 4. Testing & Debugging
- Tested all arithmetic operations for accuracy
- Verified responsive design across different screen sizes
- Ensured keyboard shortcuts work correctly
- Fixed edge cases (division by zero, consecutive operators)

## How to Run
- Clone or download the project files
- Open index.html in your web browser
- Start calculating!

## Keyboard Support
- Use number keys (0-9) for digits
- Use +, -, *, / for operations
- Press Enter for equals
- Press Escape or C for clear
