# Paul Walker Tribute Page

A tribute page for Paul Walker built with HTML, CSS, and JavaScript.

## Objective
To create a respectful and visually appealing tribute page that honors Paul Walker's life, career, and legacy.

## Features
- Responsive design for all devices
- Dark theme with red accents
- Smooth animations and hover effects
- Interactive filmography section
- Social media integration

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome Icons

## File Structure
```bash
Tribute/
├── index.html
├── tribute.css
├── tribute.js
└── images/
    ├── photo_2025-10-18_17-30-45.jpg
    ├── photo_2025-10-18_17-30-40.jpg
    └── photo_2025-10-18_17-30-41.jpg
```

## How to Run
1. Download the project files
2. Open index.html in your web browser
3. No server required

## Sections
- Hero Section with quote and image
- Quick Facts about Paul Walker
- Biography and career timeline
- Filmography with notable films
- Charity work information
- Legacy and memorial

## Customization
- Update image file paths in HTML
- Modify colors in tribute.css
- Edit text content in HTML file
- Update social links in footer

- Chrome
- Firefox
