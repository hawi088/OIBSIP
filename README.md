# OASIS Projects Collection

A collection of four web development projects built with HTML, CSS, and JavaScript.

## Objective
To demonstrate web development skills through four distinct projects showcasing different functionalities and design approaches.

## Features
- Responsive design that works on desktop and mobile devices
- Modern UI with smooth animations and interactions
- Cross-browser compatibility
- Mobile-friendly interfaces
- Local storage implementation for data persistence

## Projects Included

### 1. Calculator
A functional calculator with basic arithmetic operations and keyboard support.

### 2. Paul Walker Tribute Page
A responsive tribute page honoring Paul Walker's life and legacy with dark theme and elegant design.

### 3. To-Do Web App
A clean todo application with category organization, dark mode, and local storage.

### 4. LogIn Authentication System
A modern authentication interface with login and registration forms with smooth animations.

## How to Run
1. Navigate to any project directory within LEVEL-2 folder
2. Open the main HTML file in your web browser
3. No server required - runs directly in the browser
